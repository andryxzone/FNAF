ANDRYX FNAF - WALK FRAMES
========================

Questi sono 6 fotogrammi PNG separati dal foglio originale.
Carica i sei file walk_01.png ... walk_06.png nel repository GitHub pubblico
andryxzone/FNAF, nella cartella principale, insieme ai file già presenti.

Dopo il caricamento, gli URL saranno:
https://raw.githubusercontent.com/andryxzone/FNAF/main/walk_01.png
...
https://raw.githubusercontent.com/andryxzone/FNAF/main/walk_06.png

Dopo aver caricato i file, usa il widget HTML/CSS/JS fornito separatamente.
I fotogrammi sono PNG con trasparenza e dimensioni uniformi 340x480.
